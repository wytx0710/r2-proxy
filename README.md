# Cloudflare Worker R2 静态资源代理 & 缓存服务
一个基于 **Cloudflare Pages 边缘函数** 实现的高性能静态资源代理服务，支持 **R2 存储托管 + 源站镜像回源 + 多级缓存**，一键实现静态资源全球加速、成本优化与高可用托管。零服务器、零运维，全程依托 Cloudflare 全球 CDN 节点极速分发。

---

## ✨ 核心特性
- ✅ **请求安全校验**：仅允许 GET 请求，自动拦截非 GET 请求并返回 405，拒绝非法提交与恶意请求
- ✅ **边缘缓存优先**：Cloudflare 缓存命中直接返回内容，访问速度极致加速
- ✅ **R2 存储优先**：优先从 Cloudflare R2 对象存储读取资源，保护源站不暴露
- ✅ **智能镜像回源**：R2 无资源时，自动从源站拉取并**永久存入 R2** 持久化
- ✅ **自动缓存写入**：资源响应后异步写入边缘缓存，后续访问不再重复回源
- ✅ **标准缓存头优化**：同时优化浏览器本地缓存 + CDN 边缘缓存双重策略
- ✅ **静态网站适配**：访问根路径 `/` 自动返回 R2 内的 `index.html`

## 🔗 必做：R2 存储桶绑定
1. 提前创建 **Cloudflare R2 Bucket**
2. 进入 Pages 项目 → 设置 → 函数 → **R2 存储桶绑定**
3. **环境变量名称必须填写：`R2_BUCKET`**（代码已固定适配，不可修改）
4. 选择对应 Bucket 并保存

## 🔁 请求处理工作流程
1. 接收用户请求 → 校验请求方法，仅放行 GET
2. 优先查询 **Cloudflare 边缘缓存**，命中直接返回
3. 未命中缓存 → 从 **R2 Bucket** 读取资源
4. R2 无资源 → 从**源站下载** → 自动存入 R2 永久保存
5. 返回资源，并**异步写入边缘缓存**
6. 后续请求直接走缓存/R2，不再频繁回源

## 📄 响应头缓存优化
```http
Cache-Control: public, max-age=600, s-maxage=86400
ETag: 自动从 R2 获取
Content-Type: 自动识别资源类型
```
- `max-age=600`：浏览器本地缓存 10 分钟
- `s-maxage=86400`：Cloudflare CDN 边缘缓存 1 天

---

## 📊 状态码说明
- `200 OK`：请求成功，正常返回资源
- `405 Method Not Allowed`：非 GET 请求被拦截
- `404 Not Found`：R2 和源站均无对应资源
